# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-15

### Added

- Bilingual elder care workspace in English and Hindi (हिन्दी).
- Beers Criteria geriatric polypharmacy engine with data-driven DDI safety rules.
- Multimodal prescription digitization (photo OCR & voice transcription) with deterministic fallbacks.
- Pill strip label inspection and salt verification with desktop interactive samples.
- Local deterministic guardrails with PII redaction and prompt injection filters.
- Bounded session memory and caregiver escalation notification outbox.
- Pre-rendered accessible reviewer path and zero-secret client bundle build.
- Strict ESLint and TypeScript rules across all 4 workspaces (`core`, `shared`, `web`, `functions`).
- Full automated test suite covering unit, integration, boundary, and accessibility properties.
